# PadTV-Updates

Metadata systémových vydání PadTV.

`python scripts/release-manifest.py obraz.iso --url https://SKUTECNY-HOST/vydani.iso --output release.json --sign-key FINGERPRINT`

URL musí odkazovat na skutečně publikovaný soubor. Soukromé klíče zůstávají mimo Git. Automatický aktualizátor a rollback OS nejsou součástí 0.7. Žádné aktivní aktualizační kanály zatím nejsou zveřejněné.

[PadBridge — experimentální Android kompatibilita](https://github.com/PadTVos/PadBridge).
